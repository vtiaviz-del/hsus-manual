# Bem-vindo ao H-SUS

O **H-SUS** registra todo o caminho do paciente no hospital, da chegada na recepção até a alta. Ele também gera os documentos oficiais: prontuário, laudo de AIH, AIH e o arquivo de produção.

Este manual mostra, com as telas reais do sistema, como fazer cada tarefa. Escolha abaixo o seu setor ou comece pelos primeiros passos.

## O que cada setor faz no sistema

| Setor           | O que você faz no H-SUS                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| **Recepção**    | Abre o atendimento, identifica o paciente, faz a triagem e registra a consulta. Também recebe transferências. |
| **Ambulatório** | Acompanha o paciente em observação: medicação, procedimentos, anotações e encaminhamento.                     |
| **Enfermaria**  | Faz a admissão no leito, as evoluções de enfermagem e médicas e a saída da internação.                        |
| **Finalizados** | Consulta os atendimentos encerrados de cada mês e emite os documentos e a produção.                           |
| **Cadastros**   | Configura o hospital, os profissionais, as tabelas SUS e a numeração das AIHs.                                |
