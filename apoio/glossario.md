# Glossário

| Termo | Significado |
| --- | --- |
| **AIH** | Autorização de Internação Hospitalar. Documento numerado que autoriza e registra a internação para faturamento no SUS. |
| **Aprazamento** | Distribuição dos horários de cada medicamento ao longo do dia, conforme o intervalo prescrito. |
| **AVP** | Acesso venoso periférico. |
| **CBO** | Classificação Brasileira de Ocupações. Código da função do profissional. |
| **Caráter da internação** | Tipo de internação: eletiva, urgência ou decorrente de acidente. |
| **Check-in** | Marcação de que um medicamento foi administrado ou um exame foi coletado. É gravado na hora. |
| **CID-10** | Classificação Internacional de Doenças, 10ª revisão. |
| **CNES** | Cadastro Nacional de Estabelecimentos de Saúde. Código do hospital. |
| **CNS** | Cartão Nacional de Saúde (cartão do SUS). |
| **COFEN / COREN** | Conselho Federal / Regional de Enfermagem. |
| **CFM / CRM** | Conselho Federal / Regional de Medicina. |
| **Dígito verificador** | Último dígito do número da AIH, calculado a partir dos 12 dígitos da faixa. |
| **Encaminhamento** | Destino do paciente depois da consulta ou da observação: ambulatório, enfermaria, alta ou internação. |
| **Evolução** | Registro do acompanhamento do paciente internado, feito pela enfermagem ou pelo médico. |
| **Faixa de AIH** | Sequência de números de AIH autorizada pelo gestor para um período. |
| **HGT** | Hemoglicoteste (glicemia capilar). |
| **IBGE (código)** | Código de 7 dígitos do município, usado no laudo de AIH e na produção. |
| **LabSUS** | Sistema de laboratório para onde são enviados os pedidos de exames. |
| **Laudo de AIH** | Laudo médico que solicita a autorização da internação. |
| **Permanência** | Registro de que o paciente continua internado, com o motivo (códigos 21 a 28). |
| **Produção** | Arquivo com as internações do mês, usado no faturamento. |
| **Retificação** | Correção de uma evolução. A versão anterior fica guardada. |
| **SIH** | Sistema de Informações Hospitalares do SUS. |
| **SpO₂** | Saturação de oxigênio. |
| **Triagem** | Avaliação inicial com a classificação de risco do paciente. |
