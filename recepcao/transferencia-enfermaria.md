# Para a enfermaria

Destino para o paciente transferido que chega para ser **internado**.

{% stepper %}
{% step %}
### Abra a aba Consulta

Abra o atendimento da transferência e clique na aba **Consulta** (1).

<div data-with-frame="true"><figure><img src="../imagens/transf-consulta.png" alt="Consulta de uma transferência para a enfermaria"><figcaption><p>Consulta de uma transferência para a enfermaria</p></figcaption></figure></div>
{% endstep %}

{% step %}
### Registre o médico e o diagnóstico

Confira o **médico responsável** (2) e preencha o **diagnóstico** (3). Se quiser, escreva o plano de cuidado. A aba fica concluída com os dois campos preenchidos (4).
{% endstep %}

{% step %}
### Salve

Clique em **Salvar**. O paciente sai de Entradas e aparece em [Internações](../enfermaria/internacoes.md), **aguardando admissão**. A enfermagem segue com a [Admissão](../enfermaria/admissao.md).
{% endstep %}
{% endstepper %}
